Contigo-bench v3.1 (diff) vs v3.2 (mapping)

One model — gs://data-acq-models/detection/runs/deberta-v3-base-pb2-fixdrop_20260729T073616Z/best — run once on the shared 15,939-doc sample, then scored against both ground truths. The two GTs cover the identical document set (3,205,630 full corpus); only the spans differ.

How to read this. v3.1 and v3.2 are the same documents with two different notions of “truth.” v3.1 (diff) = every char that changed raw→anon (high recall, boundaries inferred). v3.2 (mapping) = exact canonical PII values from the sheet (high precision, coverage limited to the sheet). The same predictions score differently against each — the gap is what this doc explains.
