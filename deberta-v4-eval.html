Findings

  • Models plateaued at epoch 2. Epoch-3 predictions differ per-document but aggregate to the same F1 (bit-identical to 3 decimals) — the 3rd epoch bought nothing on these metrics.
  • Name subtype confusion, not detection failure. Merged-Name ~0.91 vs. Last Name ~0.46 (model A). The recall is there; the subtype label isn't.
  • Brand Name = 0.000 across all three models despite not being flagged data-less — a real failure (or a tiny/mislabeled eval slice) worth investigating.
  • Strong types: Email ~0.98, Street ~0.88, Organization ~0.81, Username ~0.74, Full Name ~0.83.
  • Contigo asymmetry: A scores v3.1 0.37 / v3.2 0.69; B/C flip to v3.1 ~0.62 / v3.2 ~0.29 (detection-only GTs).
