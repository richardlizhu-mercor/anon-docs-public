Mercor anonymization — worked examples

Two tracks. Embedded images are classified by Gemini vision and rewritten per category. Native document text is parsed from the file's own structure — never rasterized — and rebuilt in place. Each row shows original → how PII is located → anonymized.

What's real vs. representative: input files are synthetic (no real PII), and the boxes illustrate what the detectors emit. The anonymized outputs are produced by the actual production functions from data-acq: _do_text_redact, face_ops.blur_with_opencv, render_logo_text_fallback, render_signature, and — for the document track — extract_pdf + rebuild_pdf and rebuild_pptx. The PDF boxes and the PPTX XML diff are the real output of those functions on the synthetic inputs.

Track B · Native document text

The document body is read from its own structure. PDF is fixed-layout, so text carries real bounding boxes and is redacted by coordinate. PPTX (and DOCX/XLSX) is reflowable, so text has no boxes — the matched run's <a:t> node is rewritten structurally.
