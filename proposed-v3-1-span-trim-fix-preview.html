Proposed fix: tighten v3.1 (diff) spans

The v3.1 diff GT sometimes labels unchanged scaffolding (URL prefixes, <…@…> wrappers) because two changed tokens get merged into one block and only the block's outer edges are trimmed. This previews the fix — nothing is rebuilt yet.

The fix. Within each changed word-diff block, affix-trim each token against its counterpart (keeps opaque IDs atomic), then re-merge spans separated by a single space (rebuilds multi-word name phrases). Result: unchanged interior scaffolding is dropped, IDs stay whole, names stay together. v3.2 (mapping) is untouched.
