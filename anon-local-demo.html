TL;DR

The redesign's ir/ pipeline runs end-to-end. Gemini invents each persona, but the anonymization is internally consistent — the same person is faked identically across every name variant, their username, and their email, because the continuity is derived deterministically in-process. Gender and nationality are preserved (a Dutch woman stays a Dutch woman); organizations get clean brand names. Crucially, Gemini sees only an abstract spec (gender + nationality + kind) — never the original names or emails.

4 · How the faker keeps quality — and privacy

Gemini invents the persona; the machine keeps the continuity

For each cluster the faker sends Gemini only the abstract spec — gender, nationality, and kind (person / organization). Gemini returns one fake name (or brand). Every downstream surface — username, email local-part, case variants, legal-suffix org variants — is then derived deterministically in-process, exactly as the offline library engine does. So the LLM lifts persona quality (real-sounding, gender/nationality-matched names; clean company brands instead of gibberish) without ever touching the continuity logic.

No original PII leaves the machine

The original names, emails, and handles are never put in the prompt — a test asserts they never appear in what is sent. If Gemini returns something unusable for an entity, that entity falls back to the deterministic library engine, so the pipeline never breaks.
