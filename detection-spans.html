Real output from the scan_deberta scanner — the DeBERTa-v3 16-type token classifier — run over source text. It shows 331 detections and 296 highlighted spans across a 60-cell sample from the public pii-bench test set, not production data. Each span is colored by its normalized category: Person, Email, Phone, Location, ID, Org/Product, or URL.

The view is produced by eval/detector_viz.py, the same tool used to compare how detectors agree and diverge on real cells. Here it renders a single detector's spans in place, so you can read what the scanner caught and how it typed each region.

One caveat: DeBERTa shows span-boundary drift — entity fragmentation at the edges. The detection regions are right; the boundaries are the weak point. This viewer surfaces that behavior directly on sample text.
