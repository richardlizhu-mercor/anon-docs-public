The full pii-bench test eval (99,749 docs, 149,489 in-scope GT spans), re-scored so a detection counts only if the entire span matches exactly (identical [start,end)). Same predictions and same 16-type taxonomy as the official 100k leaderboard — only the match granularity changes from char-overlap to exact-span.

The official 100k eval is char-overlap, not exact-span. Its detection/cluster/fine are computed per character (a char counts if it falls in both a GT and a predicted span). That rewards "roughly right region." Here every metric requires the exact span.

Result: the DeBERTa encoders fall from ~0.74–0.83 char-detection F1 to 0.02–0.17 exact, because they emit boundary-drifted spans (Vanshita→shita: BIO decoded per subword token, no word-snap). qwen generates the literal surface, so it holds 0.79 and wins outright. trim exact ≈ EXACT proves the drift is mid-word subword truncation, not whitespace.
